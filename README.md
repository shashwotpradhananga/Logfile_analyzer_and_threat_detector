# Log Analyzer & Threat Detector

A beginner-friendly Python cybersecurity project that analyzes authentication logs and detects possible brute-force login activity based on failed login attempts.

This project contains two versions that demonstrate how the detection logic can be improved from a simple threshold-based approach to time-based detection.

## 📌 Project Overview

Logs are records of events generated by systems, applications, servers,
and security devices. Security analysts can analyze these logs to identify
suspicious activity.

This project focuses on detecting a possible brute-force login attack by
analyzing failed login attempts.

The project has two versions:

- **Version 1:** Detects a threat when there are 5 or more failed login attempts.
- **Version 2:** Detects a threat when there are 5 or more failed login attempts
  within a 2-minute time window.

Version 2 provides a more meaningful detection method because it considers
the timing of the failed attempts instead of only counting the total number
of failures.
